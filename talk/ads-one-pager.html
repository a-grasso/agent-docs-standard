ADS · Agent Docs Standard · a profile of AGENTS.md

Define the state, not the path.

A standard for where project knowledge lives and what shape it has, so an agent finds what it needs, when it needs it.

Why

Agents start every task cold. They starve (can't find the decision), flood (one giant CLAUDE.md), or trust docs that rotted silently.

The idea

Workflow frameworksGSD, Pocock's skills, Spec Kit, BMAD… ADSa standard for the result
prescribe the steps
/plan → /execute → /verify		prescribes the artifacts
what exists, where, in which shape
tied to one tool and today's modelsany agent, any workflow, any model
right if you followed the processcheckable after the fact: ads-lint in CI

States, not steps

Startone AGENTS.md at the root
In flightstatus in the tracker, never in the repo
Landeddecision → adr/
event → records/
rule → AGENTS.md

How you get from one to the next is your call.

Use ADS or don't. Keep the idea: specify the artifacts, let the path vary.
