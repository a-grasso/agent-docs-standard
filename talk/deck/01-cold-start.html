Why current approaches fail

Every task starts cold.

An agent remembers nothing from yesterday. It knows only what it can find in the repo, right now.

Starve

“Why is retry disabled here?” The answer is in a Slack thread from March.

The decision was made, never written where the code lives.

Flood

A 2,000-line CLAUDE.md, loaded on every task, mostly about other modules.

Everything in one file, so nothing is findable.

Rot

The doc says v2 of the API. Production runs v4. The agent believes the doc.

Nobody notices a stale doc until an agent acts on it.

Same root cause: knowledge is fragmented across chats, wikis, tickets and heads, with no agreed place or shape.
